Tamper-resistance approach

  • Vue keeps survey state inside the module instead of exposing mutable globals on window.
  • A Content Security Policy blocks inline scripts, framing, object embeds, form posts, and non-local fetch/XHR calls while allowing local JSON defaults.
  • Input validation runs before grading so malformed builder data cannot silently produce bogus scores.
  • For real exams, grade on a server. Browser-only surveys can reduce casual console edits, not stop the owner of the browser.
